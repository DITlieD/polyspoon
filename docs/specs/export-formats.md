# Export formats and model controls

Polyspoon delivers every model as GLB plus three interchange formats and a machine-readable controls file.

| File | Format | Units / axes | Carries |
| --- | --- | --- | --- |
| `*.glb` | glTF 2.0 binary (source of truth) | meters, +Y up | mesh, materials, rigs, animation clips |
| `*.obj.zip` | OBJ + MTL, stored zip | meters, +Y up | static mesh, normals, UVs, base-colour materials (Kd linear) |
| `*.fbx` | binary FBX 7.4 | meters (UnitScaleFactor 100), +Y up | static mesh, normals, UVs, phong base colour |
| `*.usdz` | USDZ (one USDA layer, 64-byte aligned, uncompressed) | metersPerUnit 1, upAxis Y | static mesh, normals, st, UsdPreviewSurface |
| `*.controls.json` | `polyspoon.model-controls` v1 | | every control (key, kind, unit, min/max/step, default, options, applied value), presets, palettes, materials, bounds |

## Where conversion runs

`src/formats` is a dependency-free converter that reads the verified GLB, bakes node transforms (flipping winding for mirrored nodes) and writes the other formats deterministically. The same code runs in three places:

- Repository CLI: `npm run export -- --family bench --out out/bench.glb --formats all` writes siblings plus `bench.controls.json`.
- Agent toolkit: the bundle ships `formats.mjs` (esbuild output of `src/formats/agent.ts`) and `model-controls.json`; `runtime.mjs build ... --formats obj,fbx,usdz|all` writes `asset.*` and always writes `asset.controls.json`.
- Hosted Worker: for a published version whose `selected.glb` is a verified primary artifact, `/api/catalog/:id` lists derived artifacts `formats/selected.obj.zip`, `formats/selected.fbx`, `formats/selected.usdz` and `formats/selected.controls.json` with their SHA-256 and byte counts, and `/api/catalog/:id/files?path=...` serves the identical bytes. Both routes require a signed-in member with `assets:read`; there is no anonymous model access.

The isolated processor is unchanged. Derived files are a pure function of bytes it already verified, so converting at delivery adds no new trust boundary, storage objects or review artifacts.

`src/formats/model-controls.json` is generated by `npm run controls:manifest` from the built-in recipe descriptors; a unit test fails when it is stale.

## Verification

`tests/export-formats.test.ts` re-imports each format with the three.js OBJ/MTL, FBX and USD loaders and checks exact bounds, triangle counts, winding against stored normals, materials, FBX version and units, USDZ alignment and stage metadata, and determinism. `scripts/verify-formats-blender.py` repeats the bounds check through Blender's importers.

## Limits

Interchange formats do not carry skins, animation, textures or vertex colours; rigged characters keep those only in the GLB. Hosted conversion runs inside the Worker request and is sized for low-poly catalog models. `llms.txt` and `prompt.txt` at the site root are public and describe the project and toolkit only.
