# Artifact download recovery

Source and procedural downloads retain separate format/identity validation. Both expose a visible loading, verified, or unavailable state with an accessible Retry action. Failed or missing metadata and files never leave an actionable download target. Retry refetches the relevant index and artifact with cache refresh, even for the same family/version. A later family revision aborts old work and prevents late results from replacing the current link.

ZIP availability requires fetched bytes with the exact indexed size/SHA-256 and a ZIP signature; HEAD alone is insufficient. Modules retain exact size/SHA-256 and fatal UTF-8 validation, and reject HTML fallback content. Paths remain exact, same-origin, family/version-specific paths. A small shared byte helper owns only size/digest verification and returns the verified byte copy; it is not a resource-loading framework. Download URLs own immutable Blob copies and are revoked on replacement or disposal. No fetched generator/module is executed.

`mountSourceDownload(host, configuration, currentDesignReady = () => true)` forwards readiness to the procedural component. It does not validate or mutate the supplied design. When readiness is false, the current-design link has no href or tab stop, its Blob is revoked, and its stale snippet is cleared/hidden with a visible explanation. Correction or cancellation restores the exact validated saved JSON and current parameter snippet. Family-default module/source availability is independent of current-edit readiness. A valid current design remains downloadable while packages are unavailable.

Focused tests retain identity/path/version/digest negatives and exact download-byte checks. Actual browser journeys inject HTTP failures for index404, stale index, missing artifact, size/digest mismatch and HTML fallback, then restore real public bytes and retry without reload. Additional cases switch families while an old response is pending, exercise caller readiness and verify cancellation/Blob ownership. Component endpoint checks on isolated4175 are supporting evidence; final grouped-inspector wiring and production-source coverage belong to integration after both source owners freeze. Existing4173/4174, geometry, migrations, public artifacts and current guides remain unchanged.

Source package license labels describe only the indexed software and the default config.json parameters. Apache-2.0 and CC0-1.0 are displayed only for their known scope. Missing or unknown declarations show unavailable without rejecting historically valid index records. Private edits acquire no license or publication approval from these labels.
