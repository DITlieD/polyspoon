# License scope

Project-authored software in this project is Apache-2.0. The complete license is in ../LICENSE and ../LICENSES/Apache-2.0.txt. This covers the original generator implementations, runtime, authoring tools, and control schemas. This declaration does not override existing third-party notices.

## Designated original starter content

The original default and curated preset parameter content for work-lantern, cottage, tree, fence, crate, boulder, and the original bench example is designated CC0-1.0. The designation covers their original generated geometry/material content when produced from those supplied designs, to the extent the project owns it. The complete dedication is in ../LICENSES/CC0-1.0.txt.

In a distributed source ZIP, config.json is the explicitly designated CC0 content file. TypeScript code and controls.json remain Apache-2.0. The manifest lists this separation. Generated outputs that incorporate external textures, meshes, fonts or other material retain those materials' terms.

New contributor recipes, presets and privately edited configurations do not acquire a project-authored or CC0 claim automatically. Obtain a contributor's explicit permission and record provenance/license scope before approving distribution. Contributors add a declaration under their recipe ID in docs/contributing/source-packages.json. Missing or unsupported declarations are rejected. Packaging preserves the author declaration and explicitly does not establish review approval.

## Exclusions

Research documents, screenshots and external references are not relicensed. Unity fixtures, Unity packages, editor templates and third-party asset content are excluded from the blanket declaration and public generator source archives. Existing dependency code retains its own license. The parent provenance ledger remains a separate authority and is not modified here.

## Dependency inventory

The portable rebuild requires Three.js 0.186.1 (MIT) and TypeScript 7.0.2 (Apache-2.0). Their exact versions, registry tarball addresses and integrity hashes come from the lockfile. TypeScript also has exact-version optional native compiler packages for different platforms. The installed host compiler's metadata and license are checked directly. All 20 optional platform packages have exact-version registry license, tarball and integrity metadata verified in licensing-dependencies.json. Their binaries are not installed or tested on this host and are not redistributed in our ZIP.

Each archive includes upstream license texts, TypeScript's NOTICE, and dependency-licenses.json. The inventory distinguishes locally inspected license texts from exact-version registry metadata for other platforms. This inventory is scoped to portable archives, not an assertion that all development or site dependencies share those two licenses.

Using the tool does not publish a design. No account, upload or automatic license transfer is part of generation.
